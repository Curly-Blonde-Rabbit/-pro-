# 黑鲨 2 Pro 原生 Linux 服务器

面向 BlackShark 2 Pro DLT-A0 的原生 Ubuntu 服务器、机内保底 Linux、双系统镜像回退，以及手机本地管理界面的源码整理。

**当前发布标识为 `v1.0.0-rc2`。这是已完成本机存储与回退验收的发布候选版，不是其他机型可直接刷入的通用 ROM，也尚未完成所有硬件与长期运行验收。**

## 已验证的本机基线

- Ubuntu 22.04.5 ARM64，开发内核 4.14.83-dlt-dev1。
- 原生运行，不依赖 Android 解密映射，也不是 QEMU 虚拟机。
- 一块可见主硬盘，A/B 系统镜像作为内部文件；不单独显示 B 盘。
- 主硬盘由原主分区与三块闲置区域线性组合，原始容量 122,102,427,648 字节。当前文件系统可用总容量约 111.87 GiB，显示值包含文件系统元数据扣除。
- 系统 A、系统 B、独立保底 Linux 均完成扩容后的启动检查；完成 B 到 A 的实际回退。
- 当前电脑的 USB SSH 独立保留；关闭网络 SSH 后，USB 维护连接仍能使用。
- 103 项回归测试通过；短时八核心、128 MiB 内存、64 MiB 写入和 10 次 USB SSH 检查通过。短时测试不等于长期稳定性认证。
- 抓包模块默认关闭；载荷缓存使用有界 RAM，不自动落盘。

## 目录

| 路径 | 内容 |
| --- | --- |
| `src/rootfs` | 本机回读的控制台、设备授权、抓包模块及服务源码 |
| `src/storage` | 主硬盘映射与存储身份检查，以及启动准备脚本 |
| `src/initramfs` | 不含设备密钥的启动与关停脚本 |
| `src/native` | 显示、触摸及启动控制相关 C 源码 |
| `kernel` | 运行基线配置及相关补丁，非独立完整内核源码树 |
| `tests` | 存储计划的只读单元测试 |
| `docs` | 架构、恢复、验收边界和发布方法 |

## 测试源码

```sh
python3 -m unittest discover -s tests -v
```

纯计划测试不创建映射、不调整网络、不修改磁盘。文件所有权测试在 Linux root 环境执行；其他环境会跳过这些测试。103 项完整本机回归还包括设备原有测试集，不能把上述单条命令的测试数等同于 103。
