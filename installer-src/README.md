# 安装器源码（install-candidate.1）

这里是完整安装候选包中工具的对应源码，不含大型payload，也不是从本目录直接执行即可安装的独立工具。网盘完整安装候选包包含根系统、启动模板、救援工具、身份初始化及全部哈希。

安装器只接受DLT-A0白名单存储布局；默认仅做校验。完整设备安装/冷启动尚未验收，显式安装需要额外的未验收候选开关。不要把离线文件镜像构建测试写成已在另一台手机安装成功。

目标已有BL解锁/AVB状态作为前置检查，工具不修改BL锁定或vbmeta。运行中的原机被RAM会话门禁拦截；本轮未对原机刷写。

测试脚本需要解压后的完整候选包payload。源码对应安装说明见 ../docs/installer-candidate.txt。
