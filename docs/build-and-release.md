# 源码整理与发布

## 当前交付边界

本目录是本机工作版本的源码快照，不是已验证的一键刷机安装包。内核源码输入、匹配工具链、厂商固件、设备特定配置与生成步骤需要在独立构建环境核对。补丁存在前后依赖，不要把目录中的补丁不加检查地全部重复应用。

`src/native` 保留原始版权头；内核和第三方组件依其自身许可证分发。当前仓库不重新许可第三方内容。公开发布内核或模块二进制前，应提供对应的完整源码与构建资料。

显示字体、Pillow 运行库、厂商固件及编译后的内核模块没有放入公开源码快照。当前手机的私人恢复集保留实际运行文件。移植到另一台设备前，应另行选择与核对这些运行依赖，并完成显示、触摸和恢复测试。

## 大文件

可以将经过清理并验证的公开安装镜像放在网盘，GitHub 仅维护源码、说明与 SHA256SUMS。当前私人的 boot 镜像和根系统归档仍含真实维护身份，不是公开安装镜像。

## 公开前检查

1. 在本目录运行 `python3 tools/verify_release.py` 校验文件完整性和禁止公开的文件类型。
2. 确认没有私钥、保存的 Wi-Fi、设备授权数据库、设备私有安装计划或原始运行日志。
3. 核对许可证和内核源码对应关系。
4. 使用无私人身份的镜像在另一台匹配设备上验证首次启动、身份初始化、USB 接管与机内回退。
5. 补完未验收项目后再把版本从 rc 改为稳定版。

这里没有自动创建 GitHub 仓库、推送提交或上传网盘文件。

## rc2 当前匹配输入补充

`kernel/accepted.config` 更新为相机驱动移除后的当前运行配置；`src/native` 补充已用于匹配模块构建的 IRIS engine、stock data 和 Makefile。这些输入仍不等同于完整内核源码树/工具链/厂商固件的清洁重建验收。
