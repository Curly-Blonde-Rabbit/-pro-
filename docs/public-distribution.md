# GitHub 与网盘发布

GitHub 放当前源码、说明、测试和校验清单。网盘将放清理私人身份后的部署文件，当前两个分享入口及安装包哈希见 [下载与校验](downloads.md)。当前源码 ZIP 不是整机镜像。

## 干净镜像的发布门槛

1. 从离线副本构建，不直接上传原机系统/主分区/救援归档。
2. 清除主机密钥、维护授权、SSH 私钥、Wi-Fi、Tailscale、设备授权记录、账号、历史、日志、机器ID和业务数据。
3. 清除 ext4 空闲块、journal、未分配 inode 中的历史内容；只删除目录或清空文件不足以抹掉原始块镜像内的凭据。
4. Boot/initramfs、救援系统、A/B、共享状态和初始化工具必须一并检查，避免首次启动从另一份身份备份恢复原机凭据。
5. 首次启动生成新主机密钥/机器ID，并通过本地可信流程录入新用户密钥；不预置发布者身份，也不默认开放免认证 root。
6. 安装器验证目标机型、存储边界和构件哈希；先具备恢复路径，再执行明确的安装操作。
7. 完成离线检查、初始化测试与匹配设备的首次启动验收，再标记公开镜像可用。

当前 public_install_image_ready=false。私人恢复快照不作为公开网盘下载包。

## 离线新身份初始化工具

`tools/personalize_offline_root.py` 仅针对带候选标记的离线目录录入用户自行生成的 Ed25519 公钥，生成新的 SSH 主机身份与 machine-id。它拒绝运行中的 `/`，拒绝覆盖已有身份，拒绝符号链接目标；不操作分区、不刷机、不启动 SSH。

完成该步骤也不会将 `ready_to_flash` 标成 true。Boot/initramfs、救援、布局初始化和首次启动仍需要单独完成。私钥由用户保管，不放进公开文件。
