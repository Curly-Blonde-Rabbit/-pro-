# 回退和维护

## 正常运行时

通过手机本地界面发起已接通的版本回退。操作先检查目标系统、当前任务、设备身份和保留数据，随后以候选方式启动，健康检查通过后确认版本。

## 正式系统启动失败

机内启动控制器使用有限试启动预算并回退到已验证版本，必要时转入独立保底 Linux。保底系统保留独立网络配置和维护 SSH，不以电脑 USB 为日常恢复的前提。

## 网络和组件

保存的网络配置与驱动分开保存。配置损坏恢复与模块级重置由对应服务处理，不能用“所有失败一律整机重启”替代组件恢复。当前蓝牙链尚未验收。

## 最后维修通道

USB SSH 是最后维修通道。关闭网络 SSH 不关闭此通道。它仍使用受信任电脑的密钥，不开放免密认证；已授权电脑的 root 维护例外仍保留。

## 私人恢复集

最新私人恢复集包含 A/B 与业务数据的稀疏归档、独立保底根系统归档、当前启动镜像、分区元数据、实际安装计划和当前维护凭据。它位于本仓库之外。

主文件系统已经跨越多个物理区域。不要再使用旧的原始单分区备份脚本，也不要向原主分区写回整个映射文件系统镜像。恢复应核对本机计划并先组装正确映射。

恢复业务系统时默认保留业务数据；整盘恢复或格式化是不同操作，不属于普通回退。分区表备份也不是整机恢复包。旧版本镜像清理后不再承诺逐个恢复历史版本；保留的是当前最新系统恢复集和机内 A/B 回退能力。
